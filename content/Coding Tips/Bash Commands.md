# Navigation
- pwd 
	- Print working directory: displays which folder you are in
- ls 
	- Shows all files and folders in your current location
- cd 
	- \[folder-path/folder-name] changes directory, moves you into a folder
- cd ..
	- moves you back out to the "parent" folder
- cd ~
	- takes you back to main user folder

# File and Folder Manipulation
- mkdir \[name]
	- creates a new folder
- touch \[filename]
	- creates a blank file
- rm \[filename]
	- deletes a file
- mv \[old-name] \[new-name]
	- changes a files name or moves it to a new path

use -v to confirm file version or if it exists
example: node -v

# Quality of Life:
- clear
	- wipes the screen so you have a fresh display
- history
	- shows a list of every command typed recently
- cat \[filename]
	- quickly displays the contents of a file in the terminal window
- you can use tab to autofill a path
