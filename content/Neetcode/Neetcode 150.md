I want to get used to asking clarifying questions like Input validity/Constraints (can the array be empty, whats the size range, etc), Edge cases (what should i return if there's no valid answer), and output format. I'll write down any clarifying questions at the start, as if i was talking to a real interviewer.

**Spaced repetition (interval-based):**

After each attempt, rate how it went and set the note's `interval` in frontmatter accordingly. The [[Review Queue]] then surfaces whatever is due (blind — you won't see which pattern it is until you click through to NeetCode).

- `:/` Needed hints → **7 days**
- `:)` Solved independently → **21 days**
- two `:)` in a row → **60 days**
